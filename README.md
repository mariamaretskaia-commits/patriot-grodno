# Память Гродненщины

Одностраничное приложение о 19 воинских и гражданских мемориалах Гродненской области:
интерактивная карта, викторина из 15 вопросов и «Паспорт патриота» с очками и значками.
Работает в обычном браузере и как Telegram Mini App.

## Быстрый старт

Откройте `dist/index.html` двойным кликом. Интернет нужен только для подложки карты:
список мест, карточки, викторина и паспорт работают без сети.

Развёрнутая версия: <https://mariamaretskaia-commits.github.io/patriot-grodno/>
(идёт из корня репозитория, поэтому `index.html` в корне — та же собранная копия).

## Разработка

```bash
npm run build     # пересобрать dist/index.html
npm run images    # подготовить фото из img/raw в img/opt
npm run coords    # сверить координаты с OpenStreetMap
npm run serve     # локальный сервер на http://localhost:8000
```

Зависимостей нет: сборка на чистом Node, обработка фото на Python + Pillow.

## Фотографии мест

Фотографии взяты из Wikimedia Commons и встроены в сборку как base64,
поэтому приложение остаётся одним файлом. Использованы только свободные
лицензии: CC0, CC BY-SA. Все снимки уменьшены до 400 px по большей стороне
и сжаты в WebP, поэтому в карточке под фото указано «снимок уменьшен» —
это требование лицензий CC BY-SA.

Под каждой фотографией показываются автор, лицензия, дата, ссылка на файл
в Commons и ссылка на условия лицензии. В разделе «Источники данных»
добавлена общая строка про фотографии.

Своё фото можно добавить на месте кнопкой «Своё фото», удалить — кнопкой
«Удалить фото» (20 очков возвращаются в пул).

В карточке фото занимает кадр 4:3. Портретные снимки вписываются целиком
(например, мемориал Шталага-324), альбомные кадрируются по ширине.

## Как обновить фотографии

```bash
python tools/fetch_photos.py discover   # собрать кандидатов в img/photo_candidates.json
# вручную записать выбранные файлы в img/photo_selection.json
python tools/fetch_photos.py fetch      # скачать в img/raw и обновить data/photo_credits.json
npm run images                          # WebP 400px
npm run build                           # пересобрать
```

Свои снимки можно положить в `img/raw/` под именем `id` места из `places.json`
(например `kurgan-slavy-grodno.jpg`), затем выполнить `npm run images`
и `npm run build`. Для снимков из внешних источников сначала добавьте их
в `data/photo_credits.json`, иначе под фото не будет подписи.

## Игровая механика

| Действие | Очки |
| --- | --- |
| Отметка «Я здесь» | 10 |
| Верный ответ в викторине (один раз за вопрос) | 15 |
| Своё фото места | 20 |
| Удаление своего фото | −20 |

Максимум — 700 очков: 19 мест × 10 + 15 вопросов × 15 + 19 фото × 20.

Значки: «Первый шаг», «Хранитель фортов», «Знаток», «Патриот Гродненщины».
Прогресс хранится в localStorage, фотографии — в IndexedDB.
Кнопка «Поделиться» использует `Telegram.WebApp.shareMessage` внутри Mini App
и `t.me/share/url` в обычном браузере.

Геолокации в приложении нет: проверка «я здесь» по GPS убрана, отметка
ставится вручную. Если рядом со шталыком или лесом с телефоном на руках
непонятно, где вы, — просто отметьте место и откройте карточку: адрес и
фотография подскажут, то ли это место.

## Адреса мест

В карточке показывается обычный адрес (улица и номер, деревня с сельсоветом
или официальный ориентир — сквер, перекрёсток, кладбище) вместо координат.
Адреса хранятся в поле `address` файла `data/places.json` и собраны по
официальным источникам: сайты райисполкомов, `mrik.gov.by`, `belarustourism.by`,
`izvezda.by`, каталоги воинских захоронений, а для части объектов — Википедия
и OpenStreetMap.

Точность разная, и это нормально: у фортов Гродненской крепости, мемориала
в Дятлово и памятников в деревнях почтового номера просто нет — там указан
ориентир. Перед публикацией стоит выехать на место и уточнить адреса
на картах.

## Достоверность координат

Координаты проверены автоматически через Nominatim и Overpass
(OpenStreetMap, ODbL) и вручную — по паспортам объектов и официальным
каталогам. Статус каждого места хранится в поле `coordStatus`:

- `verified` (7) — объект найден в OpenStreetMap по названию, совпадение до 300 м;
- `catalog` (12) — координаты официального каталога, сайта райисполкома
  или паспорта объекта; в OpenStreetMap рядом может быть размеченный объект
  под другим названием;
- `review` (0) — в OpenStreetMap размечен только населённый пункт, метка стоит
  в нём; нужна ручная сверка на местности.

Места, которые раньше числились со статусом `review`, сверены с первоисточниками:
мемориал пограничникам в Гродно (53.6726, 23.8026) — подтверждён объектом
OpenStreetMap «Помнік савецкім памежнікам» в 14 м, статус `verified`;
мемориальный комплекс Первой мировой войны в Сморгони (54.4897, 26.4204),
«Дети лихолетья» в Дятлово (53.4669, 25.3891) и орудие у вокзала в Волковыске
(53.1545, 24.449) — переведены в `catalog`.

Подробности и расстояния — в `tools/coords_report.md`. В самом приложении
статус больше не показывается: в карточке и в списке только адрес. Перед сдачей
каждое место стоит проверить на местности с телефоном.

## Карта и OpenStreetMap

Подложка — тайлы `tile.openstreetmap.org` (ODbL). В углу карты стоит
обязательная атрибуция «© OpenStreetMap contributors» со ссылкой: её нельзя
убирать, это условие лицензии. Логотип Leaflet из атрибуции убран вызовом
`map.attributionControl.setPrefix(false)` — так подпись не занимает место.
Если тайлы не загрузились, снизу карты появляется подсказка.

## Telegram Mini App

Приложение работает как **Main Mini App**: кнопка «Запустить» появляется в профиле
бота, а приложение открывается на весь экран.

Бот: [@MemoryOfTheGrodnoRegion_bot](https://t.me/MemoryOfTheGrodnoRegion_bot)

### Настройка в `@BotFather`

1. Бот уже создан, `@username` прописан в `src/app.js` (`BOT_USERNAME`).
   Токен в репозиторий не кладите: приложению он не нужен, все данные хранятся
   на устройстве.
2. Bot Settings → **Main Mini App** → укажите адрес страницы:
   `https://mariamaretskaia-commits.github.io/patriot-grodno/`
3. Режим запуска — **Fullscreen**.
4. Готово: кнопка «Запустить» в профиле бота и прямая ссылка
   <https://t.me/MemoryOfTheGrodnoRegion_bot?startapp>.
5. Опционально: Bot Settings → **Configure Mini App** — иконка и цвета
   загрузочного экрана.

Адрес должен быть HTTPS — GitHub Pages уже отдаёт его по HTTPS.
Шаги 2–5 Bot API не поддерживает, их выполняют только вручную.

### Ссылки на конкретное место

`https://t.me/MemoryOfTheGrodnoRegion_bot?startapp=<id>` открывает сразу карточку
места. Кнопка «Поделиться местом» в карточке формирует такую ссылку сама.

Идентификаторы мест — в `data/places.json` (например, `shtalag-324-grodno`).
При смене бота достаточно поменять `BOT_USERNAME` в `src/app.js` и пересобрать.

### Что используется из Telegram API

- `themeParams` — цвета темы, `themeChanged` перекрашивает интерфейс сразу
- `setHeaderColor` / `setBackgroundColor` — нативная шапка в цвете темы
- `BackButton` — возврат из карточки места
- `contentSafeAreaInset` + `viewportChanged` — отступы под «чёлку»
- `addToHomeScreen` — ярлык на домашний экран iOS
- `HapticFeedback` — вибрация при очках и значках
- `shareMessage`, `openLink` — «Поделиться» и внешние ссылки

Все вызовы проверяют версию WebApp, поэтому приложение не сыплет ошибками
в старых клиентах.
