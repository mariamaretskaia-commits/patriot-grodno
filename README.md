# Память Гродненщины

Одностраничное приложение о 19 воинских и гражданских мемориалах Гродненской области:
интерактивная карта, викторина из 15 вопросов и «Паспорт патриота» с очками и значками.
Работает в обычном браузере и как Telegram Mini App.

## Быстрый старт

Откройте `dist/index.html` двойным кликом. Интернет нужен только для подложки карты:
список мест, карточки, викторина и паспорт работают без сети.

Развёрнутая версия: <https://mariamaretskaia-commits.github.io/patriot-grodno/>
(идёт из корня репозитория, поэтому `index.html` в корне — та же собранная копия).

## Разработка

```bash
npm run build     # пересобрать dist/index.html
npm run images    # подготовить фото из img/raw в img/opt
npm run coords    # сверить координаты с OpenStreetMap
npm run serve     # локальный сервер на http://localhost:8000
```

Зависимостей нет: сборка на чистом Node, обработка фото на Python + Pillow.

## Как добавить фотографии

1. Положите снимок в `img/raw/` под именем `id` места из `places.json`
   (например `kurgan-slavy-grodno.jpg`).
2. Выполните `npm run images`.
3. Выполните `npm run build` — фото встроятся в `dist/index.html` как base64.

У мест без фотографии показывается SVG-заглушка с названием типа объекта.

## Игровая механика

| Действие | Очки |
| --- | --- |
| Отметка «Я здесь» | 10 |
| Верный ответ в викторине (один раз за вопрос) | 15 |
| Своё фото места | 20 |
| Подтверждение геолокацией (разница менее 2 км) | 5 |

Значки: «Первый шаг», «Хранитель фортов», «Знаток», «Патриот Гродненщины».
Прогресс хранится в localStorage, фотографии — в IndexedDB.
Кнопка «Поделиться» использует `Telegram.WebApp.shareMessage` внутри Mini App
и `t.me/share/url` в обычном браузере.

## Достоверность координат

Координаты проверены автоматически через Nominatim и Overpass
(OpenStreetMap, ODbL) и вручную — по паспортам объектов и официальным
каталогам. Статус каждого места хранится в поле `coordStatus`:

- `verified` (7) — объект найден в OpenStreetMap по названию, совпадение до 300 м;
- `catalog` (12) — координаты официального каталога, сайта райисполкома
  или паспорта объекта; в OpenStreetMap рядом может быть размеченный объект
  под другим названием;
- `review` (0) — в OpenStreetMap размечен только населённый пункт, метка стоит
  в нём; нужна ручная сверка на местности.

Места, которые раньше числились со статусом `review`, сверены с первоисточниками:
мемориал пограничникам в Гродно (53.6726, 23.8026) — подтверждён объектом
OpenStreetMap «Помнік савецкім памежнікам» в 14 м, статус `verified`;
мемориальный комплекс Первой мировой войны в Сморгони (54.4897, 26.4204),
«Дети лихолетья» в Дятлово (53.4669, 25.3891) и орудие у вокзала в Волковыске
(53.1545, 24.449) — переведены в `catalog`.

Подробности и расстояния — в `tools/coords_report.md`. В приложении статус виден
в карточке места и в списке. Перед сдачей каждое место стоит проверить на местности
с телефоном, сверить GPS-метку с паспортом `mrik.gov.by` и при возможности сделать фото.

## Telegram Mini App

1. `@BotFather` → `/newbot` → сохраните токен (в репозиторий его не кладите).
2. `/setmenubutton` → URL страницы на GitHub Pages.
3. Приложение читает `Telegram.WebApp.themeParams` и перекрашивает интерфейс
   в цвета темы, использует `HapticFeedback` при получении очков и значков.
