# Память Гродненщины

Одностраничное приложение о 51 воинском и гражданском мемориале Гродненской
области во всех 17 районах и Гродно: интерактивная карта, викторина из 25
вопросов и «Паспорт патриота» с очками и значками.

Приложение работает как **Telegram Mini App**: вне Telegram показывается экран-заглуска.
Прогресс, очки, значки и свои фотографии синхронизируются между устройствами
через собственный Worker на Cloudflare Workers и хранятся там в Workers KV.

## Быстрый старт

Открыть `dist/index.html` двойным кликом можно, чтобы посмотреть интерфейс:
приложение покажет экран-заглушку. Дальше нужен либо Telegram, либо
служебный параметр `?nogate=1` — он снимает замок только в браузере и никак
не меняет сервер. Чтение галереи и фото в Worker публичное (без `initData`),
запись — добавление, удаление фото и состояние — по-прежнему требует подпись.

Развёрнутая версия: <https://mariamaretskaia-commits.github.io/patriot-grodno/>
(идёт из корня репозитория, поэтому `index.html` в корне — та же собранная копия).

## Разработка

```bash
npm run build        # пересобрать dist/index.html и index.html в корне
npm run test:worker  # тесты Worker (117 проверок, моки KV)
npm run images       # подготовить фото из img/raw в img/opt
npm run coords       # сверить координаты с OpenStreetMap
npm run serve        # локальный сервер на http://localhost:8000
npm run cf:dev       # Worker локально
npm run cf:deploy    # задеплоить Worker
```

Зависимостей у сборки нет: это чистый Node, обработка фото — Python + Pillow.
Воркеры воркера и Wrangler — dev-зависимость.

## Фотографии мест

У всех 51 мест есть фотография, встроенная в сборку как base64, поэтому
приложение остаётся одним файлом. Источники разные: свободные файлы
Wikimedia Commons (CC0, CC BY-SA), а также официальные каталоги и издания —
портал «Цифровая звезда» (izvezda.by), сайты райисполкомов и музеев,
Save History (savehistory.by), «Гродненская правда» (grodnonews.by).
Для каждого снимка в `data/photo_credits.json` указаны источник, автор
и лицензия; в карточке места они показываются под фото.

Все снимки уменьшены до 400 px по большей стороне и сжаты в WebP, поэтому
в карточке под фото указано «снимок уменьшен». Кликабельных ссылок в
кредите нет: автор и лицензия остаются текстом.

Своё фото можно добавить на месте кнопкой «Своё фото», удалить — кнопкой
«Удалить фото» (20 очков возвращаются в пул).

Свои снимки уменьшаются до 1280 px и сохраняются как JPEG; они попадают
в общую галерею места и показываются другим участникам **без имени автора**:
в галерею не отдаются ни `username`, ни внутренний идентификатор файла.
Один пользователь может держать одно фото на одно место — повторная загрузка
заменяет прежнее. Фото хранятся в Workers KV; R2 в этом аккаунте не включён
и требует оплаты, поэтому байты кладутся в KV напрямую, без base64
(проверено скриптом `worker/tools/verify_blob.mjs`).

В карточке фото занимает кадр 4:3. Портретные снимки вписываются целиком
(например, мемориал Шталага-324), альбомные кадрируются по ширине.

## Как обновить фотографии

```bash
python tools/fetch_photos.py discover   # собрать кандидатов в img/photo_candidates.json
# вручную записать выбранные файлы в img/photo_selection.json
python tools/fetch_photos.py fetch      # скачать в img/raw и обновить data/photo_credits.json
npm run images                          # WebP 400px
npm run build                           # пересобрать
```

Свои снимки можно положить в `img/raw/` под именем `id` места из `places.json`
(например `kurgan-slavy-grodno.jpg`), затем выполнить `npm run images`
и `npm run build`. Для снимков из внешних источников сначала добавьте их
в `data/photo_credits.json`, иначе под фото не будет подписи.

## Игровая механика

| Действие | Очки |
| --- | --- |
| Отметка «Я здесь» | 10 |
| Верный ответ в викторине (один раз за вопрос) | 15 |
| Своё фото места | 20 |
| Удаление своего фото | −20 |

Максимум — 1905 очков: 51 место × 10 + 25 вопросов × 15 + 51 фото × 20.

Значки: «Первый шаг», «Хранитель фортов», «Знаток», «Исследователь
Гродненщины» (посетить место в каждом районе), «Краевед» (верно ответить
на вопрос в каждом районе викторины), «Патриот Гродненщины».
Прогресс хранится в localStorage, фотографии — в IndexedDB, и всё это
дополнительно синхронизируется с Worker, поэтому прогресс переносится
на другое устройство. Кнопка «Поделиться» использует
`Telegram.WebApp.shareMessage` внутри Mini App и `t.me/share/url` в обычном браузере.

Сброс прогресса очищает отметки посещений, ответы викторины и значки, но
**не трогает фотографии**: фото и очки за них остаются, иначе обещание
в окне подтверждения было бы ложью, а сервер всё равно вернул бы снимки
из своего списка. Если фотографию нужно убрать, удалите её отдельно.

Геолокации в приложении нет: проверка «я здесь» по GPS убрана, отметка
ставится вручную. Если рядом со шталыком или лесом с телефоном на руках
непонятно, где вы, — просто отметьте место и откройте карточку: адрес и
фотография подскажут, то ли это место.

## Проверки

```bash
npm run test:worker
```

151 проверка Worker: санитизация состояния, запрет чужих ключей, лимиты,
HMAC-подпись `initData`, разбор multipart, побайтовая целостность фото,
публичное чтение галереи и фото без автора, невозможность подменить
`ownPhotos` извне и анонимная запись отклоняется (401).

Клиент проверяется в headless Edge через CDP: приложение поднимается на
локальном HTTP-сервере, рядом работает подставной API, а сценарий имитирует
два разных устройства одного пользователя. Покрыты замок вне Telegram,
обход `?nogate=1`, отметки и викторина, загрузка фото с уменьшением до
1280 px, общая галерея без имени автора, постраничный показ, полноэкранный
просмотр, работа без сети и повторная отправка после её восстановления,
перенос прогресса и фото на второе устройство, удаление снимка и сброс.

Важные регрессии, которые эти проверки фиксируют:

- ответ сервера не считается новым изменением, поэтому лишних отправок нет;
- правка, сделанная пока запрос в пути, не теряется;
- фото переживают сброс прогресса.

## Адреса мест

В карточке показывается обычный адрес (улица и номер, деревня с сельсоветом
или официальный ориентир — сквер, перекрёсток, кладбище) вместо координат.
Адреса хранятся в поле `address` файла `data/places.json` и собраны по
официальным источникам: сайты райисполкомов, `mrik.gov.by`, `belarustourism.by`,
`izvezda.by`, каталоги воинских захоронений, а для части объектов — Википедия
и OpenStreetMap.

Точность разная, и это нормально: у фортов Гродненской крепости, мемориала
в Дятлово и памятников в деревнях почтового номера просто нет — там указан
ориентир. Перед публикацией стоит выехать на место и уточнить адреса
на картах.

## Достоверность координат

Координаты проверены автоматически через Nominatim и Overpass
(OpenStreetMap, ODbL) и вручную — по паспортам объектов и официальным
каталогам. Статус каждого места хранится в поле `coordStatus`:

- `verified` (21) — объект найден в OpenStreetMap по названию, совпадение до 300 м;
- `catalog` (29) — координаты официального каталога, сайта райисполкома,
  паспорта объекта или карточки izvezda.by; в OpenStreetMap рядом может
  быть размечен объект под другим названием;
- `reference` (1) — координаты взяты по описанию населённого пункта
  или справочному источнику; нужна ручная сверка на местности.

Места, которые раньше числились со статусом `reference`, сверены с первоисточниками:
мемориал пограничникам в Гродно (53.6726, 23.8026) — подтверждён объектом
OpenStreetMap «Помнік савецкім памежнікам» в 14 м, статус `verified`;
мемориальный комплекс Первой мировой войны в Сморгони (54.4897, 26.4204),
«Дети лихолетья» в Дятлово (53.4669, 25.3891) и орудие у вокзала в Волковыске
(53.1545, 24.449) — переведены в `catalog`.

Подробности и расстояния — в `tools/coords_report.md`. В самом приложении
статус больше не показывается: в карточке и в списке только адрес. Перед сдачей
каждое место стоит проверить на местности с телефоном.

## Карта и OpenStreetMap

Подложка — тайлы `tile.openstreetmap.org` (ODbL). В углу карты стоит
обязательная атрибуция «© OpenStreetMap contributors» со ссылкой: её нельзя
убирать, это условие лицензии. Логотип Leaflet из атрибуции убран вызовом
`map.attributionControl.setPrefix(false)` — так подпись не занимает место.
Если тайлы не загрузились, снизу карты появляется подсказка.

## Серверная часть

Worker: <https://patriot-grodno-api.patriot-grodno.workers.dev>

Хранилища — три отдельных namespace Workers KV, чтобы ключи не пересекались:

| Привязка | ID | Что лежит |
| --- | --- | --- |
| `STATE` | `b3c868fd546e4819abef342070b3ecc7` | `state:<userId>` — посещения, ответы, значки |
| `INDEX` | `e23e62d645de468da48efeacc22eaed2` | `photos:index` — список снимков всех участников |
| `BLOBS` | `bb6faaac811042d3aef5897ed4e1eadd` | `photo:<placeId>:<userId>.<ext>` — сами байты |

### Маршруты

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/api/health` | проверка живости, без подписи |
| `GET` | `/api/state` | состояние пользователя + его фото |
| `POST` | `/api/state` | сохранить состояние или сбросить (`{"reset":true}`) |
| `GET` | `/api/gallery?placeId=` | метаданные снимков места без данных автора |
| `POST` | `/api/photos?placeId=` | загрузить снимок (multipart, до 3 МБ) |
| `GET` | `/api/photos/:id` | отдать байты снимка |
| `DELETE` | `/api/photos/:id` | удалить свой снимок |

Все маршруты, кроме `/api/health`, требуют заголовок `X-Telegram-Init-Data`
с корректной HMAC-подписью. Без секрета Worker честно отвечает `503`, а не
молча пропускает запросы.

### Что нужно сделать один раз

Токен бота хранится только в секрете Worker, в репозитории его нет:

```bash
npx wrangler secret put BOT_TOKEN --config worker/wrangler.jsonc
```

Команда спросит значение интерактивно. Вводить токен нужно в своём терминале:
в чат, в код и в логи его класть нельзя. После установки
`GET /api/health` должен вернуть `hasBotToken: true`.

### Проверка хранилища

```bash
node worker/tools/verify_blob.mjs
```

Скрипт кладёт в `BLOBS` тестовый ключ с «невозможными» байтами, читает его
обратно и сверяет SHA-256, затем удаляет ключ. Нужен задеплоенный Worker
и авторизация Wrangler.

### Ограничения бесплатного плана

KV на бесплатном тарифе даёт 1000 записей в сутки на пространство. Запись
состояния идёт с дебаунсом 30 секунд, поэтому обычное использование укладывается
в лимит с большим запасом. Изменения отправляются пачкой: приложение шлёт
состояние только когда оно действительно поменялось, а ответ сервера не
считается новым изменением.

Значения KV не обновляются мгновенно: запись видна в другом регионе с задержкой
до минуты. Поэтому список снимков (`INDEX`) — единственный источник истины
для фото, и `ownPhotos` клиенту отдаётся отдельно от `STATE`.

## Telegram Mini App

Приложение работает как **Main Mini App**: кнопка «Запустить» появляется в профиле
бота, а приложение открывается на весь экран.

Бот: [@MemoryOfTheGrodnoRegion_bot](https://t.me/MemoryOfTheGrodnoRegion_bot)

### Настройка в `@BotFather`

1. Бот уже создан, `@username` прописан в `src/app.js` (`BOT_USERNAME`).
   Токен приложению не нужен: всё общение идёт через Worker, который
   проверяет подпись сам. В репозитории токена нет.
2. Bot Settings → **Main Mini App** → укажите адрес страницы:
   `https://mariamaretskaia-commits.github.io/patriot-grodno/`
3. Режим запуска — **Fullscreen**.
4. Готово: кнопка «Запустить» в профиле бота и прямая ссылка
   <https://t.me/MemoryOfTheGrodnoRegion_bot?startapp>.
5. Опционально: Bot Settings → **Configure Mini App** — иконка и цвета
   загрузочного экрана.

Адрес должен быть HTTPS — GitHub Pages уже отдаёт его по HTTPS.
Шаги 2–5 Bot API не поддерживает, их выполняют только вручную.

Кнопку под чатом можно поставить и через Bot API — `setChatMenuButton`
с `web_app`, тогда она ведёт прямо в приложение, минуя профиль бота.

### Ссылки на конкретное место

`https://t.me/MemoryOfTheGrodnoRegion_bot?startapp=<id>` открывает сразу карточку
места. Кнопка «Поделиться местом» в карточке формирует такую ссылку сама.

Идентификаторы мест — в `data/places.json` (например, `shtalag-324-grodno`).
При смене бота достаточно поменять `BOT_USERNAME` в `src/app.js` и пересобрать.

### Что используется из Telegram API

- `themeChanged` — сигнал, приложение всегда работает в собственной фиксированной
  тёплой палитре (тёмный коричневый фон, золотистые акценты) и не перекрашивается
  под цвета темы Telegram; чтение `themeParams` не используется
- `setHeaderColor` / `setBackgroundColor` — фирменный тёмный фон шапки `#14100b`
- `BackButton` — возврат из карточки места
- `contentSafeAreaInset` + `viewportChanged` — отступы под «чёлку»
- `addToHomeScreen` — ярлык на домашний экран iOS
- `HapticFeedback` — вибрация при очках и значках
- `shareMessage`, `openLink` — «Поделиться» и внешние ссылки

Все вызовы проверяют версию WebApp, поэтому приложение не сыплет ошибками
в старых клиентах.
